# API 與分類範圍

目前選用 Bagisto 21、Shopware 21、Sylius 22，共 64 操作。完整端點與角色見 [現行索引](selected-apis.md)，實際契約路徑見 [採用清單](api-extension/active-api-manifest.json)。

## 共同業務

商品列表／搜尋／詳情、顧客認證與地址、購物車建置及品項更新、結帳配送與付款設定、建單與查單。流程支援 API 用於取得合法狀態，也保留其正常流量；不要求各平台路徑、欄位名稱或操作數相同。

## 第一版三類

| 類別 | 定義 |
|---|---|
| normal | 非攻擊請求，包含正常流程、合法特殊字元與可預期錯誤 |
| sqli | 經人工審核、放在合理輸入位置的 SQL 注入嘗試 |
| xss | 經人工審核、放在合理輸入位置的跨站腳本注入嘗試 |

分類表示攻擊請求辨識，不代表攻擊成功或平台存在漏洞。混合或無法確認的樣本先獨立保存，不強行塞入單一類別。

CMDi 與 path_traversal 是後續候選，只有既有功能有合理輸入情境並完成人工審核後才另立實驗；不為湊類別新增不安全功能。第一版排除管理員操作、真實付款／退款，以及尚未驗證的上傳／下載等擴充功能。

所有範圍仍須在固定版本實例跑通正常流程；目前不宣稱涵蓋所有電商或已具備全平台防禦能力。
